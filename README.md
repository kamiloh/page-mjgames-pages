# page-mjgames-pages

## 项目简介

这是一个用于归档和发布多个独立 HTML 页面的仓库。仓库内包含若干静态页面，适用于快速展示、测试或资料存档场景。每个页面均为独立文件，不依赖特定域名或外部运行环境。

## 目录说明

```
├── README.md          # 本说明文件
├── index.html         # 入口页面（可选）
├── pages/             # 存放各独立 HTML 页面
│   ├── example1.html
│   ├── example2.html
│   └── ...
└── assets/            # 共享资源（CSS、JS、图片等）
    ├── style.css
    └── script.js
```

- `pages/`：主要页面归档目录，每个 HTML 文件为一个独立页面。
- `assets/`：存放页面间可能共用的样式、脚本或图像资源。

## 页面归档说明

- 所有页面均为静态 HTML，可直接在浏览器中打开浏览。
- 页面之间无强制依赖关系，可单独使用。
- 归档内容不涉及具体网站或服务，仅作为页面集合存储。

## 维护说明

- 新增页面时，请将 HTML 文件放入 `pages/` 目录，并保持命名简洁。
- 若页面需要共用资源，请统一放在 `assets/` 下，避免重复。
- 不建议在页面中嵌入外部域名或敏感信息，保持通用性。
- 欢迎提交 Pull Request 添加或更新页面，但请确保内容符合归档用途。

## 许可

本仓库仅用于页面存档，不涉及特定许可证。使用者可自由浏览、下载或引用仓库内的页面文件。
